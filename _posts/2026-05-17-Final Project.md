CLUB PACK Final

My motivation behind the project was to have a bag that I can bring on a night out. It was a fun project that I can use in the future as my party trick (since I don't have one). I also don't like to have things in my pocket, but bags can be ugly. So this is a solution to have a styleish bag. 

The bag has three main componets. First there are four LED lights that blink every three seconds. They run continuously on a loop and in any environemnt. Secondly, there is a RGB light which runs on an input from a light sensor. When it is dark the RGB turns on and will change between random colors. When it is light the RGB will turn off. This is so I can really show off inside the club, and bring the party. Lastly, there is a buzzer that runs off of a switch. When the switch is on it will play a little tune. When the switch is off it will be silent. This is so if I need fresh air I can keep the party going outside.

The material list for the project is a fannypack, black thread, conductive thread, arduino, battery, RGB light, light sensor, four lilypad LED lights, switch, and a buzzer. 

Three tips to my past self is to give myself enough time for the project. This is a long project and I should have started earlier. Secondly, I would consider that conponets that I want hidden on the inside of the bag will be flipped. I did not consider this before, so I had to redesign my paper prototype to accomidate for this. Lastly, I would use this fabric again. It was very convenent for wires crossing. It creates a natural bridge so that wire can cross over eachother easily. It insulates itself.
